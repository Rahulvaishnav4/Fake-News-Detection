Abstract
Phishing attacks have emerged as one of the most significant cybersecurity threats in
the modern digital landscape. These attacks exploit human psychology through social
engineering and deceptive websites to steal sensitive information such as login credentials,
financial data, and personal identification details. The increasing sophistication and rapid
evolution of phishing techniques necessitate the development of intelligent, adaptive, and
explainable detection systems.
This project presents anExplainable and Adaptive Machine Learning Frame-
work for Phishing Website Detectionthat leverages URL-based characteristics to
classify websites as either legitimate or phishing.
The system implements and compares multiple classical machine learning algorithms
including Logistic Regression, Random Forest, Support Vector Machine (SVM), XG-
Boost, Gradient Boosting Classifier, CatBoost, Decision Tree, K-Nearest Neighbors,
Multi-layer Perceptron, and Naive Bayes. Additionally, the framework explores deep
learning models such as Artificial Neural Networks (ANN) and Long Short-Term Mem-
ory (LSTM) networks for enhanced detection capabilities.
A critical contribution of this work is the integration of Explainable Artificial Intelli-
gence (XAI) techniques, specifically SHAP (SHapley Additive exPlanations) and LIME
(Local Interpretable Model-agnostic Explanations), to provide human-understandable
explanations for each prediction. This transparency is essential for building trust in
automated security systems and enabling security analysts to understand the factors
contributing to classification decisions.
The experimental results demonstrate that the Gradient Boosting Classifier achieves
the highest accuracy of 97.4%, with an F1-score of 0.977, Recall of 0.994, and Precision of
0.986. The feature importance analysis reveals that URL characteristics such as HTTPS
token, Anchor URL, Website Traffic, and URL length are among the most significant
predictors of phishing activity.
The framework is deployed as a web application using Flask, providing a simple and
intuitive interface where users can submit URLs and receive immediate classification
results along with detailed explanations of the contributing features. The modular archi-
tecture ensures maintainability and facilitates future extensions toward adaptive learning,
real-time crawling, and concept drift detection.

Chapter 1
Introduction
1.1 Project Overview
The Internet has become an indispensable part of modern life, facilitating communication,
commerce, education, and entertainment. However, this widespread connectivity has also
provided opportunities for malicious actors to perform various cyberattacks, with phishing
being one of the most prevalent and dangerous threats.
Phishing is a form of social engineering attack where attackers deceive victims by
creating mockup websites that closely resemble legitimate services. These fraudulent
websites are designed to steal sensitive information such as account IDs, usernames,
passwords, credit card details, and other personal information from individuals and orga-
nizations. According to recent cybersecurity reports, phishing attacks have consistently
ranked among the top attack vectors, with millions of phishing websites being detected
annually.
1.1.1 Problem Statement
Traditional phishing detection approaches, including blacklist-based methods and heuris-
tic rules, struggle to keep pace with the rapidly evolving tactics of phishers. Attackers
continuously modify their techniques to evade detection, creating new phishing URLs and
websites at an unprecedented rate. Blacklist-based approaches suffer from a fundamental
limitation: they can only detect known phishing URLs and fail against newly created
ones. Heuristic methods, while more flexible, often produce high false positive rates.
Machine learning offers a promising solution to this challenge. By analyzing patterns
and characteristics of URLs, machine learning models can identify phishing attempts
based on learned features rather than explicit rules. This enables detection of previously
unseen phishing URLs, providing a more robust and adaptive defense mechanism.

1.1.2 Project Objectives
The primary objectives of this project are:
1. To develop a comprehensive machine learning framework for phishing website de-
tection using URL-based characteristics.
2. To implement and compare multiple machine learning algorithms including Logistic
Regression, Random Forest, SVM, XGBoost, and Gradient Boosting.
3. To explore deep learning approaches including Artificial Neural Networks (ANN)
and LSTM for enhanced detection.
4. To integrate Explainable AI techniques (SHAP/LIME) for transparent and inter-
pretable predictions.
5. To develop a user-friendly web interface for URL submission and result visualiza-
tion.
6. To create a modular, maintainable architecture that supports future extensions.
1.2 Scope of the Project
The scope of this project encompasses the complete machine learning pipeline required
to detect phishing websites from URL-based features. This includes:
•Collection and preprocessing of publicly available phishing and legitimate URL
datasets.
•Exploratory Data Analysis (EDA) to identify patterns distinguishing phishing URLs
from legitimate ones.
•Feature selection and feature engineering based on lexical, host-based, and content-
based URL characteristics.
•Development and comparison of multiple machine learning models.
•Exploration of deep learning models including ANN and LSTM.
•Evaluation using Accuracy, Precision, Recall, F1-Score, ROC-AUC, and False Neg-
ative Rate.
•Development of a web-based interface for user interaction.
The system is designed as a research and decision-support tool. Real-time browser-
based deployment, adaptive/online learning, and concept-drift detection are identified as
extensions for future work.

Chapter 2
Literature Survey
2.1 Introduction to Phishing Detection
Phishing detection has been an active area of research for over two decades. The litera-
ture encompasses various approaches, from early rule-based systems to modern machine
learning and deep learning techniques. This chapter reviews significant contributions in
the field and establishes the foundation for the proposed framework.
2.2 Blacklist-Based Approaches
Early phishing detection systems relied primarily on blacklists - databases of known phish-
ing URLs. While effective for known threats, blacklists suffer from several limitations:
•Reactive Nature:Blacklists can only detect URLs that have already been iden-
tified and reported as phishing.
•Update Lag:There is typically a delay between the emergence of a new phishing
campaign and its addition to blacklists.
•Evasion:Attackers can easily create new URLs that are not yet blacklisted.
Prakash et al. (2010) demonstrated that blacklist-based approaches miss a significant
portion of phishing attacks, particularly zero-day attacks.
2.3 Heuristic and Rule-Based Approaches
Heuristic approaches use predefined rules to identify phishing characteristics. Common
heuristics include:
•URL length exceeding a threshold
13

=== PAGE 14 ===
•Presence of IP address instead of domain name
•Use of @ symbol in URLs
•Excessive subdomains
•Suspicious keywords in URL
Zhang et al. (2007) proposed a heuristic-based system called CANTINA that analyzed
webpage content for phishing detection. While more flexible than blacklists, heuristic
approaches often produce high false positive rates.
2.4 Machine Learning Approaches
Machine learning has emerged as the dominant approach for phishing detection. Various
algorithms have been applied with promising results:
2.4.1 Classical Machine Learning
•Logistic Regression:Simple and interpretable, suitable for baseline comparison.
•Random Forest:Ensemble method that handles high-dimensional data well.
•Support Vector Machine (SVM):Effective for high-dimensional feature spaces.
•Decision Trees:Interpretable but prone to overfitting.
•Naive Bayes:Fast but assumes feature independence.
Abdelhamid et al. (2014) compared multiple machine learning algorithms for phishing
detection and found that Random Forest and SVM achieved the highest accuracy.
2.4.2 Ensemble Methods
Ensemble methods combine multiple base learners to improve prediction accuracy:
•Gradient Boosting:Sequentially builds models to correct errors of previous mod-
els.
•XGBoost:Optimized gradient boosting with regularization.
•CatBoost:Handles categorical features effectively.
Le et al. (2018) demonstrated that ensemble methods outperform single classifiers for
phishing detection.

2.5 Deep Learning Approaches
Deep learning has shown promise for phishing detection, particularly for complex pattern
recognition:
2.5.1 Artificial Neural Networks (ANN)
Multi-layer Perceptron (MLP) networks can learn non-linear relationships between fea-
tures. Sahingoz et al. (2019) achieved 97.98% accuracy using ANN for phishing detection.
2.5.2 Recurrent Neural Networks (RNN/LSTM)
LSTM networks are particularly suited for sequential data like URLs. They can capture
long-range dependencies in URL strings. Bahnsen et al. (2017) used LSTM for phishing
URL detection with promising results.
2.5.3 Convolutional Neural Networks (CNN)
CNNs can extract local patterns from URL strings. Le et al. (2018) applied CNN for
URL-based phishing detection.
2.6 Explainable AI in Security
The black-box nature of complex machine learning models presents challenges for security
applications where understanding decisions is crucial. Explainable AI (XAI) techniques
address this:
2.6.1 SHAP (SHapley Additive exPlanations)
SHAP, introduced by Lundberg and Lee (2017), provides consistent and locally accurate
feature attributions based on Shapley values from cooperative game theory.
2.6.2 LIME (Local Interpretable Model-agnostic Explanations)
LIME, proposed by Ribeiro et al. (2016), explains predictions by approximating the
model locally with an interpretable model.
2.7 Research Gap and Motivation
Despite significant advances, several gaps remain:

Chapter 3
Requirement Specification
3.1 General Requirements
This chapter describes the functional capabilities of the system, the actors that interact
with it, its constraints, and its supplementary requirements.
3.1.1 Functionalities
The system provides the following functionalities:
1.Data Ingestion:Load and preprocess phishing and legitimate URL datasets,
handling missing values and inconsistent entries.
2.Feature Extraction:Extract lexical features (URL length, use of ’@’ or ’-’ sym-
bols, sub-domain count, presence of IP address, HTTPS usage) and other relevant
features from a URL.
3.Feature Selection:Identify the most relevant subset of features to improve model
performance and reduce redundancy.
4.Model Training:Train and tune multiple machine learning models (Logistic Re-
gression, Random Forest, SVM, XGBoost, Gradient Boosting, CatBoost) and deep
learning models (ANN, LSTM) on the processed dataset.
5.Model Evaluation:Compute Accuracy, Precision, Recall, F1-Score, ROC-AUC,
and False Negative Rate for each model, and generate confusion matrices for com-
parison.
6.Model Selection:Select the best-performing model as the baseline predictive
model based on the evaluation metrics.
7.Prediction:Accept a URL as input and classify it as “Phishing” or “Legitimate.”

8.Explainability:Generate a SHAP or LIME-based explanation showing which
features most influenced a given prediction.
9.Web Interface:Allow a user to submit a URL through a simple web page and

The proposed system follows a modular architecture that separates concerns and facil-
itates maintainability, testing, and future extension. The architecture comprises five
major modules:

the classification.
4.Explainability and Reporting (M4):Generates SHAP/LIME explanations and
exposes evaluation information.
5.Web Interface (M5):Provides URL submission and presentation of predictions
and explanations.

implemented.
